Design & Engineering

Built for Daily Use

OctaviOS refines stock Android with granular system customization while keeping source trees close to upstream AOSP.

Octavi Lab Dashboard

Centralized settings menu for lockscreen styles, battery icons, status bar clock alignments, network speed meters, and gesture behaviors.

Security & Signature Spoofing

SELinux Enforcing across official builds. Native microG signature spoofing permissions with isolated app sandboxing and SafetyNet pass.

Thermal & Deep Sleep Tuning

Upstream Linux kernel optimizations, per-app refresh rate limiters, and aggressive deep sleep schedulers to prevent standby battery drain.

Ergonomic Card UI

Clean header offsets and reachable card grouping across Settings, reducing thumb strain on modern tall aspect-ratio displays.

Generic System Images (GSI)

Project Treble ARM64 A/B system builds for devices without dedicated maintainers. Verified on Unisoc, MediaTek, and Qualcomm platforms.

Community Maintained

Completely transparent Git repositories. Community contributions are reviewed via GitHub pull requests with continuous automated builds.

Installation Wiki

Standard flashing flow for AOSP custom recoveries (OrangeFox, TWRP, or Lineage Recovery).

1

Unlock Bootloader & Backup

Ensure OEM unlocking is enabled. Back up internal storage, photos, and authenticator keys.

2

Boot Custom Recovery

Boot your device's verified TWRP or OrangeFox recovery image via fastboot.

3

Format Data (Mandatory for clean flash)

Navigate to Wipe > Format Data and confirm typing yes to remove file-based encryption keys.

4

Sideload or Flash Zip

Flash the ROM package via ADB Sideload or Install menu, followed by reboot to system.

fastboot / adb terminal
bash 
# 1. Verify fastboot device connectivity
fastboot devices

# 2. Boot into custom recovery
fastboot boot recovery.img

# 3. Enter sideload mode in recovery & flash
adb sideload OctaviOS-v3.9-OFFICIAL.zip

# 4. Reboot into OctaviOS
fastboot reboot
