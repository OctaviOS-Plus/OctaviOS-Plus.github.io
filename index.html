Standard Operating Procedures

Installation Guide

Pick your preferred installation method. Ensure your bootloader is unlocked prior to flashing.

1
Backup & Boot Recovery

Boot your verified custom recovery (OrangeFox, Lineage Recovery, or TWRP) via fastboot.

2
Mandatory Clean Wipe

Go to Wipe > Format Data > type yes to remove previous vendor encryption tokens.

3
Sideload ROM Package

Under recovery, select Apply update from ADB, connect USB, and execute sideload.

Terminal (adb sideload) 
# Verify connected device
adb devices

# Sideload the downloaded OctaviOS archive
adb sideload OctaviOS-Release-OFFICIAL.zip

# Reboot into OctaviOS system
adb reboot
1
Enter FastbootD Mode

Boot device into bootloader, then transition into fastbootd dynamic partitions.

2
Flash Partitions

Flash boot, dtbo, vendor_boot, and system partitions sequentially.

Terminal (fastbootd) 
# Transition to fastbootd
fastboot reboot fastboot

# Flash boot images
fastboot flash boot boot.img
fastboot flash vendor_boot vendor_boot.img

# Erase user data and reboot
fastboot -w
fastboot reboot
1
No Data Wipe Required

When updating from a previous OctaviOS build, internal storage and user accounts remain intact.

2
Flash & Wipe Cache Only

Wipe Dalvik Cache before rebooting to let the ART compiler regenerate bytecode.

Terminal (OTA dirty-flash) 
# Direct sideload over existing install
adb sideload OctaviOS-Update-latest.zip

# No data format required — reboot straight to system
adb reboot
Developers & Maintainers

Build from Source

Interested in porting OctaviOS to your device? Our trees are open-source and modular. Initialize our manifest repository via Google repo tool:

# Initialize Android 14 manifest
repo init -u https://github.com/OctaviOS-Plus/manifest -b 14 --depth=1
# Synchronize source trees
repo sync -c -j$(nproc --all) --force-sync
